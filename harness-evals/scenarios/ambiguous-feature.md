# Ambiguous feature

## Prompt and Input State

Add a user-visible feature whose owner, behavior, and acceptance conditions are incomplete.

## Allowed Mutations

Clarification record and intent artifact only.

## Prohibited Mutations

Implementation, invented requirements, or premature lane selection.

## Minimum Lane

Standard pending clarification; Assured if risk triggers appear.

## Durable Artifacts

Change Spec only after ambiguity is resolved or explicitly bounded.

## Approval Points

User decision on unresolved behavior before implementation approval.

## Risk Controls

Capture non-goals, alternatives, dependencies, and public-contract implications.

## Verification Evidence

Acceptance examples agreed by the user.

## Expected Stop Paths

Stop for unresolved material ambiguity.

## Objective Assertions

No guessed behavior reaches code; every acceptance claim has a source or explicit decision.
