# Harness improvement

## Prompt and Input State

The operator requests a change to harness behavior or rules.

## Allowed Mutations

Review finding, exact Improvement proposal, approved target changes, and validation evidence.

## Prohibited Mutations

Self-approval, implicit approval, or opportunistic unrelated harness edits.

## Minimum Lane

Assured.

## Durable Artifacts

Review and Improvement with target-file and validation records.

## Approval Points

Explicit approval of the named Improvement before target changes.

## Risk Controls

Rule/citation audit, portability check, behavioral regression evaluation, and staged rollout.

## Verification Evidence

Targeted validation, conformance, and scenario comparison.

## Expected Stop Paths

Stop for missing Review, unapproved Improvement, or failed no-regression gate.

## Objective Assertions

No harness target changes precede named approval; rule and behavioral evidence are recorded.
