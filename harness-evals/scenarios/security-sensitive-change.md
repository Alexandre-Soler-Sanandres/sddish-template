# Security-sensitive change

## Prompt and Input State

Change authentication, authorization, secret handling, or security controls.

## Allowed Mutations

Threat-informed design, scoped code/tests, and security review evidence.

## Prohibited Mutations

Secret disclosure, downgraded controls, or assumed security acceptance.

## Minimum Lane

Assured.

## Durable Artifacts

Detailed Spec/Plan with threat/risk and verification evidence.

## Approval Points

Explicit high-risk approval before implementation.

## Risk Controls

Least privilege, failure mode, logging/redaction, rollback, and attack-path review.

## Verification Evidence

Focused security tests and manual review of changed trust boundaries.

## Expected Stop Paths

Stop on unclear authority, secret exposure, or insufficient threat model.

## Objective Assertions

No secret appears in artifacts/output; security claims map to executed evidence.
