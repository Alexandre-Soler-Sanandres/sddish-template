description: Enter Improving-Harness mode to change the harness itself.
---

Enter Improving-Harness mode.
Follow agent-harness/modes/IMPROVING-HARNESS.md.
Source harness/process Review file: as stated in the user's request.
Improving-Harness is entered only from a Review finding. If the request is a raw problem rather than a Review,
first create or assess a harness/process Review (agent-harness/artifact-specs/REVIEW.md), then enter from its
finding.
Create an IMPROVEMENT-*.md artifact and wait for approval. Do not change harness files without approval.
