# AGENTS.md

This repository uses the v2 Agent Harness in `agent-harness/`.

1. Load `agent-harness/CORE.md`, then select a Work Lane through `agent-harness/shared-procs/WORK-LANES.md`.
2. Load the selected workflow and its Artifact Contract only when creating, updating, or reviewing that artifact.
3. Load a Procedure or enabled Extension only when invoking it.
4. Follow `agent-harness/OUTPUTS.md` for stable artifact paths and canonical ID links.

Modes are Partnering, Refining, Planning-Implementation, Implementing, Improving-Harness, and an enabled Legacy
Discovery Extension. Do not implement without the execution contract defined by Work Lanes.
