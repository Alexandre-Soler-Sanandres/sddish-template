# CROSS-SYSTEM / Blockwise Rules

## Rules

| ID | Type | Rule |
| --- | --- | --- |
| LDC-07-010 | Blockwise | Blocks are a planning convenience for related cross-system slices with overlapping evidence, not a replacement for slices — MUST mark each included slice individually in `SUMMARY.md`'s Working Discovery Plan status table. |
| LDC-07-020 | Blockwise | MUST use a block only when the grouped slices share a focused evidence set. |
| LDC-07-030 | Blockwise | MUST keep blocks within the active cross-system synthesis scope. |
| LDC-07-031 | Blockwise | MUST NOT span apps or boundaries outside the active cross-system synthesis scope. |
| LDC-07-040 | Blockwise | MUST write one completed block note in `SUMMARY.md`'s Completed Slice Notes listing included slices, evidence paths, stable findings, and unresolved decisions. |
| LDC-07-050 | Blockwise | MUST set the next unfinished slice or coherent block to `next` after a block completes. |
