# Intent Validation

## Purpose

Confirm that the requested behavior solves the right problem before approval or implementation.

## Procedure

1. Compare the request, requirements, constraints, and preserved behavior.
2. Resolve or record material ambiguity as Questions.
3. Confirm the result is complete, consistent, feasible, and verifiable.
4. Record changed requirements in the owning artifact; do not claim technical verification.

## Rules

| ID | Rule |
| --- | --- |
| INV-01-010 | Intent Validation MUST assess correctness, completeness, consistency, feasibility, and verifiability. |
| INV-01-020 | Material uncertainty MUST become a canonical Question or be resolved before promotion. |
| INV-01-030 | Intent Validation MUST NOT claim to have run technical checks. |
